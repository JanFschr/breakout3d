# Breakout3D

Ein mit [Three.js](https://threejs.org/) und [Vite](https://vite.dev/) erstelltes 3D-Breakout-Spiel.

## Entwicklung

```bash
npm install
npm run dev
```

Der Produktions-Build wird mit `npm run build` erstellt. Pull Requests durchlaufen automatisch Linting und Build; Änderungen auf `main` werden für GitHub Pages bereitgestellt.
